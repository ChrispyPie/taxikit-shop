**Status:** bara mock. Ingen kod, ingen SQL, inget live.

## Modell (senaste)
- Växel: **Topplista | Rekord**
- **Samma listor i båda lägena** (dagens Topplistor-listor + enskilda körningar: längsta, kortaste, högsta belopp).
- **Topplista** = vald aktuell period (Dag/Vecka/Månad/År + datumväljare).
- **Rekord** = bästa någonsin för den periodlängden sedan jan 2025 (ingen datumväljare).
- Förare/Bil bara i Topplista. Anonym ranking, "Du" markerad.
