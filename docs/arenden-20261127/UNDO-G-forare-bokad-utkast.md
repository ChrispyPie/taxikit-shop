# Förare kan föreslå Bokad tid + Utkast (2026-11-27utkast1)
**Bara UI, ingen SQL.** `mailbox-ui.js`.
- **Bokad tid från Nytt ärende (förare):** knappen Bokad tid i dialogen Nytt ärende öppnar samma bokningsformulär som admin (Typ/rubrik, datum i kalender, 24-timmars tid, Meddelande, Bil nr med Nej förvalt och bilfrågan från #257). Meddelandet är obligatoriskt när föraren skapar en ny tråd (UI-krav, servern kräver det inte). Servern (`mailbox_v2` `book`) tillät redan förarförslag (`pending_admin`) så inga RPC/RLS-ändringar. Admin kan acceptera/avböja/omboka/avboka, listan visar ?.
- **Utkast:** `localStorage` nyckel `taxi_mx_draft:<förar-id>:<a|d>:<sammanhang>` (a=admin, d=förare). Sammanhang: `compose`, `booking:new|t<tråd>|i<ärende>`, `reply:t:<tråd>`, `reply:c:<typ>:<id>`. Sparas medan man skriver, återställs när formuläret/tråden/ärendet öppnas, tas bort när det skickas eller slängs, äldre än 30 dagar rensas, alla utkast rensas vid utloggning (`U.logout`). Utkast-rad överst i listan (bara kategori Alla, ingen personfiltrering). Tips Utkast sparat/återställt och Släng utkast i formulär och svarsrutor. Ombokningsformuläret, Sjuk och Verkstadstimmar (andra moduler) sparas inte.
- Tester: `node tests/arenden-20261127/utkast.cjs`, `tests/arenden-20261127/utkast.py`, `tests/arenden-20261127/bokad-forare.py` (390 px, ljust + mörkt). `tests/inkorg-v2/browser.py` rad 68 uppdaterad (Bokad tid i dialogen).
**Backup:** `backup/main-before-forare-bokad-tid-20261127`. **Cache:** `20261127utkast1`. Nyheter `2026-11-27utkast1`, `2026-11-27forarbokad1`.
## Ångra
`git revert -m 1 <merge-commit>`, höj cache, PR + merge. Ingen force-push. Ingen SQL. Sparade utkast ligger kvar i enhetens localStorage men visas inte efter revert; de kan rensas med `Object.keys(localStorage).filter(k=>k.startsWith('taxi_mx_draft:')).forEach(k=>localStorage.removeItem(k))`.
