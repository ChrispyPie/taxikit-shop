# Valkompass

Interactive party alignment test.

**Concept:**
1. User selects the party they currently support / think they align with.
2. Answers a series of short rapid-fire questions.
3. Gets a ranked list of how well they match all parties.
4. Can click each party for a short explanation of why they match or don't.

This is a "reality check" style compass, not a classic matching quiz.

## Status
Early development. Testing via existing domain/app first.
